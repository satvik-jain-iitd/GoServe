One section per session, per `docs/PLAN.md` section 5. Short lines.

## Decided

- Host the investor doorway site on Cloudflare Pages, under a temporary domain
  (`letsdwelo.in`), with Astro. See ADR-001, ADR-002, ADR-003.
- Make the repo public, so free CI checks and branch protection work.

## Surprised

- The n8n webhook body is nested under `json.body`, and the Mongo node replaces
  the item, which made the alert blank.
- `wrangler` cannot manage Pages custom domains.
- The public n8n API can create credentials, but cannot attach tags.
- A closing keyword does not close an issue when the merge goes to `dev`, only
  to `main`.

## Dropped

  404 for our key. Tag attach stays a manual UI step (follow-up F14).
